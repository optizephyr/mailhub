# 分诊标签

技能用五个标准分诊角色说话。本文件把这些角色映射到本仓库议题跟踪器里的实际标签字符串。

| mattpocock/skills 中的角色 | 本仓库标签 | 含义 |
| -------------------------- | ---------- | ---- |
| `needs-triage`             | `needs-triage`       | 维护者需要评估该议题 |
| `needs-info`               | `needs-info`         | 等待报告人补充信息 |
| `ready-for-agent`          | `ready-for-agent`    | 规格已齐，可供无人值守 agent 执行 |
| `ready-for-human`          | `ready-for-human`    | 需要人来实现 |
| `wontfix`                  | `wontfix`            | 不会处理 |

技能提到某个角色时（例如「打上 AFK-ready 分诊标签」），使用上表右侧对应的标签字符串。

若仓库实际用的标签名不同，只改右列即可。
